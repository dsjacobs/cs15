4. Consider implementing the handling of the input "backspace." What
are the different cases your implementation must consider? What
should your implementation do in each case; specifically, how are the
inputs to TextUI's render() function altered? You should play around
with the reference implementation when coming up with your answers.

Answer:
At the top the file (0,0), pressing backspace does nothing.

At the beginning of any line but the first (x>=1,any y), backspace deletes 
the new line character and moves the cursor to the end of the previous line. 
(Subtract 1 from x, and y is end of previous line). 

When the cursor is in any column but the first (any x, y>=1), backspace should 
erase the previous letter (and add it to the action stack so that it can later
be undone if needed). (X stays the same, subtract 1 from y).

Answer:
def undo() {
// make sure there is what to undo
while (UndoActionStack.isNotEmpty())
{
   // identify top element
   char Action = UndoActionStack.top();   

   // if its a new line character treat that as a one off
   if (Action.char == '\n') {
      DoneActionStack.pop();
   }

   // if its a backspace
   if (Action.char == BACKSPACE) {
      // go until the next non-backspace
      DoneActionStack.pop();
      char newTop = DoneActionStack.top();
      while (newTop.char == BACKSPACE) {
         undo();
         }
   }

   // ignore anything that happens with arrow keys
   else if (elem not in (UP, DOWN, LEFT, RIGHT))
   {   
      // keep removing characters until I hit new line or backspace
      undo();
   }
}
}

def redo() {
// make sure there is what to redo
while (UndoneActionStack.isNotEmpty())
{
   // identify top element
   char elem = UndoneActionStack.top();   

   // if its a new line character treat that as a one off
   if (elem == '\n') {
      UndoneActionStack.pop();
   }

   // if its a backspace
   if (elem == BACKSPACE) {
      // go until the next non-backspace
      UndoneActionStack.pop();

         redo();
         }

   // ignore anything that happens with arrow keys
   else if (elem not in (UP, DOWN, LEFT, RIGHT))
   {   
      // keep removing characters until I hit new line or backspace
